# Module 9 — JS Essentials For Backend Development

Module 8-এ আমরা OOP, JSON, আর higher-order function নিয়ে দ্রুত পরিচিত হয়েছিলাম, ডেটা মডেলিং আর API ডিজাইনের বড় ছবিটা বোঝার জন্য। এই মডিউলে আমরা সেই ভিত্তিটাকেই আরও ধীরে, গভীরভাবে, খুঁটিনাটিসহ ঝালাই করেছি — কারণ array আর object-ই হলো সেই মৌলিক উপাদান, যা দিয়ে ব্যাকএন্ডের প্রতিটা ডেটা প্রকাশ পায়।

## এই মডিউল শেষে তুমি যা পারবে

- জাভাস্ক্রিপ্টের primitive ও object টাইপগুলো স্পষ্টভাবে আলাদা করতে পারবে
- object আর array of objects দিয়ে বাস্তব ডেটা মডেল করতে পারবে
- destructuring দিয়ে পরিষ্কার, সংক্ষিপ্ত কোড লিখতে পারবে (বিশেষ করে Express route handler-এ)
- `filter`, `map`, `reduce`, `find` ব্যবহার করে array of objects নিয়ে কাজ করতে পারবে
- query parameter থেকে ফিল্টারিং, সার্চিং, আর হালকা পেজিনেশন বাস্তবায়ন করতে পারবে

এই মডিউল বিল্ড হয়েছে Module 8-এর ভিত্তির উপর, আর সরাসরি সহায়ক Module 4-এ শেখা `let`/`var`/`const` আর জাভাস্ক্রিপ্ট বেসিকসের জন্য।
