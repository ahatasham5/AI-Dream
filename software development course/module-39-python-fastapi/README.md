# Module 39 — Python FastAPI

এই মডিউলে আমরা Python-এর FastAPI ফ্রেমওয়ার্ক ব্যবহার করে কয়েকটা বাস্তব প্রজেক্ট বানাবো — একটা সাধারণ REST API দিয়ে শুরু করে, AI চ্যাটবট, ভিডিও প্রসেসিং টুল, একটা কনটেন্ট মেটাডেটা জেনারেটর, আর সবশেষে এই Python সার্ভিসগুলোকে একটা Node.js membership app-এর সাথে সংযুক্ত করা।

## এই মডিউল শেষে তুমি যা পারবে

- FastAPI দিয়ে Pydantic মডেল ব্যবহার করে একটা validated REST API বানাতে পারবে
- OpenAI API ব্যবহার করে একটা কথোপকথনমূলক AI ফিচার বানাতে পারবে
- ffmpeg/pydub দিয়ে ভিডিও/অডিও প্রসেসিং সার্ভিস বানাতে পারবে
- Structured JSON output-সহ একটা LLM-ভিত্তিক মাইক্রো-টুল ডিজাইন করতে পারবে
- Node.js আর Python সার্ভিসকে একসাথে একটা সিস্টেমে সংযুক্ত করতে পারবে, দায়িত্ব স্পষ্টভাবে ভাগ করে
