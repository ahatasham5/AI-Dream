# Module 4 — Javascript With Node.Js And Express.Js

Module 3-এ আমরা বড় ছবিটা দেখেছি — কেন Node.js, কীভাবে বিভিন্ন সার্ভার একসাথে কাজ করে। এই মডিউলে আমরা হাতে-কলমে কাজে নামি: JavaScript-এর কয়েকটা মৌলিক ধারণা ঝালিয়ে নিয়ে, Express.js দিয়ে প্রথম প্রকৃত ওয়েব সার্ভার বানাই, সেটাকে Postman/Thunder Client দিয়ে টেস্ট করি, URL দিয়ে ডেটা পাঠানোর দুটো পদ্ধতি শিখি, একাধিক backend-কে একে অপরের সাথে কথা বলাই, আর Python-এর FastAPI-র সাথে তুলনা করে দেখি ব্যাকএন্ডের মূল ধারণাগুলো ভাষা-নিরপেক্ষ কীভাবে।

## এই মডিউল শেষে তুমি যা পারবে

- Callback কী এবং কেন Node.js-এ এত ঘন ঘন ব্যবহৃত হয় তা ব্যাখ্যা করতে পারবে
- `let`, `var`, আর `const`-এর মধ্যে সঠিক পার্থক্য বুঝে যথাযথভাবে ব্যবহার করতে পারবে
- Express.js দিয়ে রুট-ভিত্তিক একটা ওয়েব সার্ভার নিজে হাতে বানাতে পারবে
- Postman বা Thunder Client দিয়ে API টেস্ট করতে পারবে, ব্রাউজার ছাড়াই
- Path Parameter আর Query Parameter-এর পার্থক্য বুঝে সঠিক জায়গায় ব্যবহার করতে পারবে
- `fetch` বা `axios` ব্যবহার করে একটা backend থেকে আরেকটা backend-কে কল করতে পারবে
- বুঝবে কেন Express.js আর FastAPI-এর মতো ভিন্ন ভাষার framework গঠনগতভাবে একই রকম
