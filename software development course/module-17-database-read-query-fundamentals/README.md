# Module 17 — Database Read Query Fundamentals

Module 16-এ আমরা টেবিল বানাতে শিখেছি। এই মডিউলে আমরা প্রথমবারের মতো সেই টেবিল থেকে ডেটা "পড়া" শিখবো — `SELECT` দিয়ে শুরু করে, ফিল্টার, গ্রুপিং, সর্টিং পর্যন্ত, আর সবশেষে বুঝবো এই SQL-চিন্তাভাবনা আমাদের আগে থেকে জানা জাভাস্ক্রিপ্টের array method-এর সাথে কতটা মিলে যায়।

## এই মডিউল শেষে তুমি যা পারবে

- `SELECT` দিয়ে নির্দিষ্ট কলাম বেছে নিতে এবং `WHERE` দিয়ে সারি ফিল্টার করতে পারবে
- `GROUP BY`, `HAVING` আর aggregate function (`COUNT`, `SUM`, `AVG`) দিয়ে জটিল রিপোর্ট-স্টাইল কোয়েরি লিখতে পারবে
- `ORDER BY` দিয়ে ফলাফল সাজাতে পারবে
- SQL-এর declarative চিন্তাভাবনাকে জাভাস্ক্রিপ্টের `filter`/`map`/`reduce`/`sort`-এর সাথে তুলনা করে ব্যাখ্যা করতে পারবে
