## এই মডিউল শেষে তুমি যা পারবে

- Branch তৈরি, সুইচ, merge, আর rebase করতে পারবে, আর কোনটা কখন ব্যবহার করবে বুঝবে
- সহজ ও জটিল merge conflict আত্মবিশ্বাসের সাথে সমাধান করতে পারবে
- Remote repository, fork, clone, push, pull/fetch দিয়ে টিমে কাজ করতে পারবে
- Pull Request workflow আর কোড রিভিউ প্রক্রিয়া পরিচালনা করতে পারবে
- Git Flow, GitHub Flow, আর Trunk-Based Development-এর মধ্যে সঠিক পছন্দ করতে পারবে
- stash, cherry-pick, reset, revert, tag, submodule, monorepo, hooks, signing, আর interactive rebase ব্যবহার করতে পারবে
- একটা টিম রিপোজিটরি সঠিকভাবে সেটআপ করতে এবং Git থেকে সরাসরি deployment চালাতে পারবে
