# Module 13 — Typescript With OOP

এতদিন আমরা যা কিছু লিখেছি — Node.js সার্ভার, Express রুট, JWT, কুকি — সবকিছু প্লেইন JavaScript দিয়ে লিখেছি। এই মডিউলে আমরা প্রথমবার TypeScript-এর জগতে ঢুকবো, বুঝবো কেন বড় প্রজেক্টে টাইপ দরকার হয়, আর তারপর Object-Oriented Programming (OOP)-এর চারটা মূল স্তম্ভের প্রথম তিনটা আর Class/Inheritance-এর ভিত্তি গড়ে তুলবো।

## এই মডিউল শেষে তুমি যা পারবে

- TypeScript কেন ব্যবহার করা হয় এবং JavaScript থেকে এটা কীভাবে আলাদা তা ব্যাখ্যা করতে পারবে
- `ts-node` আর `tsconfig.json` দিয়ে নিজের TypeScript প্রজেক্ট সেটআপ করতে পারবে
- Express অ্যাপ্লিকেশনে `@types/express` ব্যবহার করে টাইপ-সেফ রুট লিখতে পারবে
- Encapsulation ও Abstraction ব্যবহার করে বাস্তব-জীবনের সমস্যার মডেল বানাতে পারবে
- Class লিখতে ও Inheritance দিয়ে কোড পুনর্ব্যবহার করতে পারবে
