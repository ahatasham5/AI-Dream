## এই মডিউল শেষে তুমি যা পারবে

- NestJS-এর মিডলওয়্যার, গার্ড, ইন্টারসেপ্টর পাইপলাইন ব্যাখ্যা করতে পারবে
- JWT + Passport দিয়ে অথেন্টিকেশন ও কাস্টম RBAC গার্ড দিয়ে অথরাইজেশন বসাতে পারবে
- গ্লোবাল Exception Filter দিয়ে কনসিস্টেন্ট এরর হ্যান্ডলিং করতে পারবে
- API ভার্সনিং ও রেট লিমিটিং প্রয়োগ করতে পারবে
- Jest দিয়ে ইউনিট ও e2e টেস্ট লিখতে পারবে
- Kafka দিয়ে ইভেন্ট-ড্রিভেন যোগাযোগ ও WebSocket দিয়ে রিয়েল-টাইম ফিচার বানাতে পারবে
- Redis দিয়ে ক্যাশিং স্ট্র্যাটেজি প্রয়োগ করতে পারবে
- Monolith বনাম Microservices আর্কিটেকচারের পার্থক্য ও ট্রেড-অফ বুঝতে পারবে
- Docker ও CI/CD দিয়ে একটা NestJS অ্যাপ প্রোডাকশনে ডিপ্লয় করতে পারবে
