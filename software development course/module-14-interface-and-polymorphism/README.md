# Module 14 — Interface And Polymorphism

Module 13-তে আমরা Class আর Inheritance শিখেছি — কীভাবে একটা ক্লাস আরেকটা ক্লাসের বৈশিষ্ট্য "উত্তরাধিকার" সূত্রে পায়। এই মডিউলে আমরা সেই ভিত্তির উপর দাঁড়িয়ে OOP-এর শেষ বড় ধারণা — Polymorphism আর Interface — শিখবো, আর দেখবো বাস্তব ব্যাকএন্ড সিস্টেমে (যেমন পেমেন্ট গেটওয়ে) এগুলো কীভাবে কাজে লাগে।

## এই মডিউল শেষে তুমি যা পারবে

- Polymorphism কী এবং কেন এটা OOP-র জন্য গুরুত্বপূর্ণ তা ব্যাখ্যা করতে পারবে
- একই মেথড নাম বিভিন্ন ক্লাসে ভিন্নভাবে ইমপ্লিমেন্ট করে Polymorphism দেখাতে পারবে
- Interface লিখে একাধিক ক্লাসের মধ্যে একটা কমন "চুক্তি" (contract) বেঁধে দিতে পারবে
- পেমেন্ট গেটওয়ে বা নোটিফিকেশন সার্ভিসের মতো বাস্তব সিস্টেম ডিজাইনে Interface ও Polymorphism প্রয়োগ করতে পারবে
