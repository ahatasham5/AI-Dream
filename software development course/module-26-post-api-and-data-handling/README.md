## এই মডিউল শেষে তুমি যা পারবে

- Multer দিয়ে নিরাপদভাবে ফাইল আপলোড হ্যান্ডল করতে পারবে (সাইজ, টাইপ, নামকরণ)
- কাস্টম `AppError` ক্লাস আর কেন্দ্রীয় error-handling middleware দিয়ে POST এরর সামলাতে পারবে
- Mass Assignment, বড় পেলোড, আর ব্রুট-ফোর্সের মতো ঝুঁকি চিনতে ও ঠেকাতে পারবে
- Zod/express-validator দিয়ে allow-list ভিত্তিক ইনপুট ভ্যালিডেশন করতে পারবে
