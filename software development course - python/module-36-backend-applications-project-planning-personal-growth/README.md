# Module 36 — Backend Applications Project Planning: Personal Growth

এই মডিউল একটা একক, ধারাবাহিক প্রজেক্ট জার্নাল — আমরা শুরু থেকে শেষ পর্যন্ত একটা বাস্তব অ্যাপ্লিকেশন, **Personal Growth Tracker** (habit, goal, journal ট্র্যাকিং অ্যাপ), পরিকল্পনা করবো, AI-সহায়ক টুল দিয়ে সজ্জিত হবো, বানাবো, deploy করবো, আর সুরক্ষিত করবো। প্রতিটা লেসন আগেরটার উপর দাঁড়িয়ে আছে — এটা বিচ্ছিন্ন টপিকের তালিকা না, বরং একটা প্রজেক্টের ডায়েরি।

## এই মডিউল শেষে তুমি যা পারবে

- একটা প্রজেক্ট শুরুর আগে OOP, ডেটাবেজ, আর্কিটেকচার ডায়াগ্রাম আঁকতে পারবে
- Requirement, scope, আর timeline পরিকল্পনা করতে পারবে
- দৈনন্দিন ডেভেলপমেন্টে AI টুল (Copilot, Cursor) ব্যবহার করতে পারবে কোড, রিভিউ, টেস্ট, আর ডকুমেন্টেশনে
- একটা fullstack অ্যাপ পরিকল্পনা থেকে production deployment পর্যন্ত সম্পূর্ণভাবে বানাতে পারবে
- CI/CD পাইপলাইন, caching, error handling, আর নিরাপত্তা একটা বাস্তব প্রজেক্টে প্রয়োগ করতে পারবে
