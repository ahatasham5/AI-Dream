# Module 42 — Building AI Agents

Module 41-এ আমরা শিখেছি বাইরের সার্ভিসের সাথে যোগাযোগ করতে। এই মডিউলে আমরা এক ধাপ এগিয়ে যাই — একটা AI (LLM)-কে নিজের সিস্টেমের ভেতরে বসিয়ে দেয়া, যেটা শুধু টেক্সট জেনারেট করে না, বরং নিজে সিদ্ধান্ত নিয়ে বাস্তব কাজ (টুল কল, ডাটাবেজ অ্যাক্সেস) করতে পারে। বেসিক আর্কিটেকচার থেকে শুরু করে মাল্টি-এজেন্ট সিস্টেম, সেফটি, প্রোডাকশন ডেপ্লয়মেন্ট, মনিটরিং, আর একটা সম্পূর্ণ ফাইনাল প্রজেক্ট পর্যন্ত পুরো যাত্রা এই দশটা লেসনে কভার করা হয়েছে।

## এই মডিউল শেষে তুমি যা পারবে

- AI এজেন্টের মৌলিক আর্কিটেকচার (perceive-decide-act loop) ব্যাখ্যা করতে পারবে
- LangChain দিয়ে টুল-ব্যবহারকারী এজেন্ট বানাতে পারবে
- টাস্ক-স্পেসিফিক ডিজাইন, মেমোরি, আর মাল্টি-এজেন্ট রাউটিং প্রয়োগ করতে পারবে
- Prompt Injection-এর মতো ঝুঁকি প্রতিরোধে সেফটি গার্ডরেল বসাতে পারবে
- একটা এজেন্টকে নিরাপদে প্রোডাকশনে ডেপ্লয় ও মনিটর করতে পারবে
