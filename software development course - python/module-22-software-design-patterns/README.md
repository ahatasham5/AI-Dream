# Module 22 — Software Design Patterns - Theory With Implementations

Module 13 আর Module 14-তে আমরা OOP-এর ব্যাকরণ (Class, Encapsulation, Inheritance, Protocol, Polymorphism) শিখেছিলাম। এই মডিউলে আমরা সেই ব্যাকরণ দিয়ে "ভালো গল্প" লেখার প্রমাণিত কৌশল শিখবো — Design Pattern। এখানে তত্ত্বের পাশাপাশি প্রতিটা প্যাটার্নের জন্য বাস্তব, চলমান Python কোড আছে, যাতে পরের মডিউলে FastAPI শেখার সময় এই ধারণাগুলো তোমার কাছে অপরিচিত না লাগে।

## এই মডিউল শেষে তুমি যা পারবে

- ব্যাখ্যা করতে পারবে Design Pattern কেন দরকার, আর কখন প্যাটার্ন ব্যবহার করা উচিত না (over-engineering এড়ানো)
- নিজে হাতে Dependency Injection প্রয়োগ করে tight coupling দূর করতে পারবে
- Factory Pattern দিয়ে অবজেক্ট তৈরির লজিক কেন্দ্রীভূত করতে পারবে
- Strategy Pattern দিয়ে রানটাইমে অ্যালগরিদম/আচরণ অদলবদল করতে পারবে
- Decorator Design Pattern (অবজেক্ট wrap করা) আর Python-এর `@` decorator সিনট্যাক্স (ফাংশন wrap করা) — এই দুটোর মধ্যে স্পষ্ট পার্থক্য বুঝতে পারবে
- এই সব ধারণা নিয়ে ইন্টারভিউ প্রশ্নের আত্মবিশ্বাসী উত্তর দিতে পারবে
