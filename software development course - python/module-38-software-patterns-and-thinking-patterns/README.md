## এই মডিউল শেষে তুমি যা পারবে

- OOP-এর চারটা স্তম্ভ (encapsulation, abstraction, inheritance, polymorphism) ব্যাখ্যা ও প্রয়োগ করতে পারবে
- SOLID নীতি অনুসরণ করে নমনীয়, টেস্টযোগ্য কোড ডিজাইন করতে পারবে
- সাধারণ code smell চিনতে এবং নিরাপদে refactor করতে পারবে
- CAP Theorem ব্যাখ্যা করতে পারবে এবং বিতরণকৃত সিস্টেম ডিজাইনে trade-off বুঝতে পারবে
- অর্থবহ নামকরণ, ছোট ফাংশন, আর দরকারী কমেন্টের মাধ্যমে clean code লিখতে পারবে
