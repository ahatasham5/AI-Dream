# ০২. Setting Up Go Development Environment

আগের লেসনে আমরা বুঝেছি Go কেন তৈরি হয়েছিলো, এবার হাত নোংরা করার পালা। যেকোনো ভাষা শেখার প্রথম বাধা হলো এনভায়রনমেন্ট সেটআপ — আর ভালো খবর হলো, Go এই ব্যাপারে বেশ বন্ধুত্বপূর্ণ।

Go ইনস্টল করতে যেতে হবে অফিসিয়াল সাইট **go.dev**-এ, সেখান থেকে নিজের অপারেটিং সিস্টেম (Windows, macOS, Linux) অনুযায়ী ইনস্টলার ডাউনলোড করে ইনস্টল করলেই হয়ে যায় — অনেকটা Node.js ইনস্টল করার মতোই সহজ। ইনস্টলেশন শেষে টার্মিনালে গিয়ে যাচাই করে নাও:

```bash
go version
```

এটা দেখাবে তোমার সিস্টেমে কোন ভার্সনের Go বসেছে, যেমন `go version go1.22.0 linux/amd64`।

এখানে একটা ঐতিহাসিক প্রসঙ্গ বলা দরকার — পুরনো দিনে Go প্রজেক্ট বানাতে হলে একটা নির্দিষ্ট ফোল্ডার কাঠামো (**GOPATH**) মেনে চলতে হতো, যেখানে সব Go কোড একটা নির্দিষ্ট গ্লোবাল ফোল্ডারের ভেতরেই রাখতে হতো। এটা অনেকটা এমন যেন npm-এর আগে সবাইকে একটাই গ্লোবাল ফোল্ডারে সব প্রজেক্ট রাখতে বলা হতো — অস্বস্তিকর আর সীমাবদ্ধ। ২০১৮ সালে Go **Modules** নিয়ে আসে, যেটা npm-এর `package.json`-এর মতোই প্রতিটা প্রজেক্টকে তার নিজের জায়গায়, নিজের ডিপেন্ডেন্সি তালিকাসহ স্বাধীনভাবে থাকতে দেয়। Modules নিয়ে বিস্তারিত থাকবে এই মডিউলের একটা পরের লেসনে, কিন্তু এখন থেকেই জেনে রাখা ভালো যে আধুনিক Go ডেভেলপমেন্ট মানেই Modules-ভিত্তিক ডেভেলপমেন্ট, GOPATH নয়।

একটা সাধারণ Go প্রজেক্টের ফোল্ডার কাঠামো দেখতে এমন হয়:

```
my-go-project/
├── go.mod
├── main.go
└── internal/
    └── helper.go
```

এডিটর হিসেবে আমরা এই কোর্সে যে **VS Code** ব্যবহার করছি (Module 1-এ যেটা ইনস্টল করা শিখেছিলে), সেটাই যথেষ্ট — শুধু Extensions ট্যাব থেকে অফিসিয়াল **"Go" extension** (Google-এর তৈরি) ইনস্টল করে নিলেই VS Code Go কোডের জন্য syntax highlighting, auto-completion, আর error detection দিতে শুরু করবে।

এবার প্রথম প্রোগ্রাম লেখা যাক। `main.go` নামে একটা ফাইল তৈরি করো:

```go
package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
```

আর টার্মিনালে রান করো:

```bash
go run main.go
```

এটা সাথে সাথে কম্পাইল করে আউটপুট দেখিয়ে দেবে — `Hello, Go!`। লক্ষ্য করো, এখানে Node.js-এর মতো `node main.js` লিখে সরাসরি ইন্টারপ্রেট হচ্ছে না; বরং Go প্রথমে কোডটা কম্পাইল করে একটা এক্সিকিউটেবল বাইনারি বানায়, তারপর সেটা চালায় — আর পুরো প্রক্রিয়াটা এতটাই দ্রুত যে পার্থক্য চোখে পড়ে না।

পরের লেসনে আমরা Go-এর সিনট্যাক্স আর ডেটা টাইপগুলো নিয়ে বিস্তারিত আলোচনা করবো।
