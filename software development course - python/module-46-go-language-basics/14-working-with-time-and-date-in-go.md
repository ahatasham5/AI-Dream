# ১৪. Working with Time and Date in Go

প্রায় প্রতিটা ব্যাকএন্ড সিস্টেমেই কোনো না কোনোভাবে সময় নিয়ে কাজ করতে হয় — কখন একটা অর্ডার তৈরি হলো, একটা সেশন কতক্ষণ আগে শুরু হয়েছিলো, বা একটা টোকেন কখন মেয়াদ শেষ হবে। Go-তে এই সবকিছুর জন্য একটা মাত্র জায়গা — standard library-এর `time` প্যাকেজ।

বর্তমান সময় জানতে চাইলে:

```go
package main

import (
    "fmt"
    "time"
)

func main() {
    now := time.Now()
    fmt.Println(now) // 2026-08-08 15:04:05.123456 +0600 +06 m=+0.000123456
}
```

`time.Now()` একটা `time.Time` টাইপের ভ্যালু ফেরত দেয়, যার ভেতরে বছর, মাস, দিন, ঘণ্টা, মিনিট, সেকেন্ড, এমনকি টাইমজোন পর্যন্ত সব তথ্য থাকে।

এবার আসি Go-এর সবচেয়ে অদ্ভুত অথচ চমৎকার একটা ব্যাপারে — সময় **ফরম্যাটিং**। অন্য অনেক ভাষায় ফরম্যাট লিখতে হয় `YYYY-MM-DD` এই ধরনের symbolic কোড দিয়ে। Go সম্পূর্ণ ভিন্ন পথ নিয়েছে — এখানে একটা নির্দিষ্ট **রেফারেন্স তারিখ** মুখস্থ রাখতে হয়:

```
Mon Jan 2 15:04:05 MST 2006
```

এই তারিখটা আসলে সংখ্যার একটা প্যাটার্ন — মাস ১, দিন ২, ঘণ্টা ৩ (15), মিনিট ৪, সেকেন্ড ৫, বছর ৬ (06), আর সপ্তাহের দিন উপরে। এটা মুখস্থ করার একটা সহজ কৌশল হলো সংখ্যাগুলো পড়া: ০১/০২ ০৩:০৪:০৫ ০৬। তুমি যেভাবে চাও ঠিক সেভাবে এই রেফারেন্স তারিখটাকেই সাজিয়ে লেখো, Go বুঝে নেয় তুমি কী ফরম্যাট চাইছো।

```go
now := time.Now()

fmt.Println(now.Format("2006-01-02"))             // 2026-08-08
fmt.Println(now.Format("02 Jan 2006"))             // 08 Aug 2026
fmt.Println(now.Format("15:04:05"))                // 15:04:05 (24-ঘণ্টা ফরম্যাট)
fmt.Println(now.Format("Mon, 02 Jan 2006 15:04"))  // Sat, 08 Aug 2026 15:04
```

কেন এত অদ্ভুত একটা সিস্টেম? কারণ এখানে ভুল হওয়ার সুযোগ কম — `MM` আর `mm`-এর মধ্যে গুলিয়ে ফেলার ঝুঁকি নেই, বরং তুমি সরাসরি লিখছো তারিখটা দেখতে কেমন হবে। একবার অভ্যস্ত হয়ে গেলে এটা আসলে বেশ স্বজ্ঞাত মনে হয়।

স্ট্রিং থেকে সময় ফেরত পেতে (parsing) একই রেফারেন্স ফরম্যাট ব্যবহার করা হয়:

```go
parsed, err := time.Parse("2006-01-02", "2026-08-08")
if err != nil {
    fmt.Println("তারিখ পার্স করতে সমস্যা:", err)
}
fmt.Println(parsed.Year(), parsed.Month(), parsed.Day())
```

সময়ের সাথে সময় যোগ-বিয়োগ করতে দরকার হয় **duration**। Go-তে duration মানে একটা নির্দিষ্ট সময়ের ব্যবধান, যেমন ৫ সেকেন্ড, ২ ঘণ্টা:

```go
future := now.Add(2 * time.Hour) // এখন থেকে ২ ঘণ্টা পরে
diff := future.Sub(now)          // দুইটা সময়ের ব্যবধান
fmt.Println(diff)                // 2h0m0s

if now.Before(future) {
    fmt.Println("এখনো ভবিষ্যতের সময় আসেনি")
}
```

`time.Duration` টাইপটা লেসন ০৭-এ আমরা যে goroutine নিয়ে কথা বলেছিলাম, সেখানেও ফিরে আসবে — মনে আছে হয়তো `time.Sleep(2 * time.Second)` লিখে কোনো goroutine-কে কিছুক্ষণ থামিয়ে রাখা যায়? সেই একই duration টাইপ এখানেও কাজ করছে।

পরের লেসনে আমরা দেখবো Go-এর `testing` প্যাকেজ দিয়ে কীভাবে কোড টেস্ট লেখা যায়, বাহ্যিক কোনো লাইব্রেরি (Jest বা Mocha-র মতো) ছাড়াই।
