## এই মডিউল শেষে তুমি যা পারবে

- Web server, IP address, domain, port, localhost — এই ধারণাগুলোর মধ্যে সম্পর্ক ব্যাখ্যা করতে পারবে
- Node.js-এর বিল্ট-ইন `http` মডিউল দিয়ে নিজে একটা সার্ভার লিখতে পারবে
- একটা HTML ফাইল সার্ভার থেকে সঠিকভাবে ব্রাউজারে পাঠাতে পারবে
- একটা cloud VM-এ SSH দিয়ে ঢুকে সার্ভার ডেপলয় করতে পারবে
