# ০৩. Definition of a Webserver

আগের দুই লেসনে আমরা দুইভাবে একটা HTML পাতা খুলেছি — একবার সরাসরি ডিস্ক থেকে, একবার Live Server নামক একটা ছোট প্রোগ্রামের মধ্য দিয়ে। এই দ্বিতীয়টায় যে জিনিসটা নতুন করে দেখলাম, সেটাকেই এখন একটা পরিষ্কার সংজ্ঞায় বাঁধবো।

একটা উপমা দিয়ে শুরু করি। ধরো একটা রেস্টুরেন্টে তুমি বসে আছো, একজন ওয়েটার আছে। তুমি অর্ডার দিলে "একটা বিরিয়ানি দাও", ওয়েটার রান্নাঘরে গিয়ে খাবারটা নিয়ে আসে, তোমার টেবিলে দিয়ে যায়। ওয়েটার নিজে বিরিয়ানি বানায় না, কিন্তু সে জানে কোথা থেকে আনতে হবে, আর কার কাছে পৌঁছে দিতে হবে।

**Web server** হলো ঠিক এই ওয়েটারের মতো একটা প্রোগ্রাম। ব্রাউজার (তুমি, যে খাবার চাইছো) একটা অনুরোধ পাঠায় — "আমাকে index.html পাঠাও"। ওয়েব সার্ভার (ওয়েটার) সেই অনুরোধ শোনে, ডিস্ক থেকে (রান্নাঘর) ফাইলটা খুঁজে বের করে, তারপর সেটা ব্রাউজারের কাছে ফেরত পাঠায়।

তার মানে সংজ্ঞাটা দাঁড়ায় এরকম: **Web server হলো এমন একটা প্রোগ্রাম, যেটা নেটওয়ার্কের মাধ্যমে আসা অনুরোধ (request) গ্রহণ করে, এবং সেই অনুরোধের জবাবে একটা উত্তর (response) পাঠায় — সাধারণত একটা ওয়েবপেজ, একটা ছবি, বা অন্য কোনো ডেটা।**

এই সংজ্ঞাটায় তিনটা জিনিস লক্ষ্য করার মতো:

প্রথমত, ওয়েব সার্ভার সবসময় **অপেক্ষায়** থাকে। এটা নিজে থেকে কিছু করে না, যতক্ষণ না কেউ অনুরোধ পাঠায়। এই "অপেক্ষায় থাকা" অবস্থাটাকে বলে **listening** — সার্ভার একটা নির্দিষ্ট ঠিকানা আর পোর্টে "কান পেতে" বসে থাকে, কেউ ডাকলেই সাড়া দেয়।

দ্বিতীয়ত, প্রতিটা অনুরোধের একটা নির্দিষ্ট জবাব থাকে। তুমি `index.html` চাইলে সে `index.html` পাঠাবে, `about.html` চাইলে সে `about.html` পাঠাবে। এই মিলটা কীভাবে হয়, সেটা আমরা পরের লেসনগুলোতে বিস্তারিত দেখবো।

তৃতীয়ত, "ওয়েব সার্ভার" শব্দটা দুই অর্থে ব্যবহার হয় — কখনো এটা বোঝায় একটা **সফটওয়্যার** (যেমন Live Server, Nginx, Apache, অথবা আমরা নিজে Node.js দিয়ে যেটা বানাবো), আবার কখনো এটা বোঝায় একটা **শক্তিশালী কম্পিউটার/মেশিন** যেখানে সেই সফটওয়্যারটা চলে (যেমন কোনো ডেটা সেন্টারে বসানো একটা মেশিন, যাকে মানুষ বলে "সার্ভার রুম")। প্রসঙ্গ দেখে বোঝা লাগে কোনটা বলা হচ্ছে — এই কোর্সে আমরা মূলত প্রথম অর্থে, অর্থাৎ সফটওয়্যার হিসেবে ওয়েব সার্ভারের কথা বলবো, কারণ Node.js দিয়ে আমরা সেই সফটওয়্যারটাই বানাবো।

এখন যেহেতু আমরা জানি ওয়েব সার্ভার আসলে কী, স্বাভাবিক প্রশ্ন আসে — এই সার্ভারটা তুমি কীভাবে খুঁজে পাও ইন্টারনেটে? তুমি তো ঠিকানার বারে টাইপ করো `google.com`, একটা নাম — কিন্তু কম্পিউটার তো নাম বোঝে না, সংখ্যা বোঝে। এই প্রশ্নের উত্তর খুঁজতেই পরের লেসনে যাচ্ছি — Domain name আর IP address-এর সম্পর্ক।
