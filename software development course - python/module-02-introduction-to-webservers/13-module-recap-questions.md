# ১৩. এই মডিউল শেষ করার পরে যে টপিক গুলোর উত্তর দিতে পারতে হবে!

Module 1-এর শেষে আমরা যেমন নিজেকে যাচাই করেছিলাম, এখানেও একই কাজ করবো — নোট না দেখে, নিজের ভাষায়, নিচের প্রশ্নগুলোর উত্তর দেয়ার চেষ্টা করো। যদি কোনোটার উত্তর আটকে যায়, সেই সংশ্লিষ্ট লেসনটা আরেকবার পড়ে নাও, কারণ Module 3 থেকে আমরা এই ভিত্তির উপর দাঁড়িয়েই এগোবো।

## নিজেকে যাচাই করার প্রশ্নমালা

**১. `file://` আর `http://` — এই দুই ধরনের ঠিকানার মধ্যে মূল পার্থক্য কী?**
(ইঙ্গিত: একটায় সরাসরি ডিস্ক থেকে পড়া হয়, আরেকটায় মাঝে একটা প্রোগ্রাম থাকে।)

**২. ওয়েব সার্ভারকে যদি এক বাক্যে সংজ্ঞায়িত করতে বলা হয়, তুমি কী বলবে?**
(ইঙ্গিত: request, response, listening — এই শব্দগুলো ব্যবহার করে চেষ্টা করো।)

**৩. Domain Name আর IP Address-এর মধ্যে সম্পর্কটা কী, আর DNS এখানে কী ভূমিকা পালন করে?**
(ইঙ্গিত: ফোনবইয়ের উপমাটা মনে করো।)

**৪. Localhost (127.0.0.1) বলতে কী বোঝায়, আর এটা কেন ডেভেলপমেন্টের সময় দরকারি?**

**৫. IP address আর Port নম্বরের মধ্যে পার্থক্য কী — একটা উদাহরণ দিয়ে ব্যাখ্যা করো।**
(ইঙ্গিত: ভবন আর কক্ষ নম্বরের উপমা।)

**৬. তুমি যদি এখনই একটা খালি ফাইলে বসে Node.js দিয়ে সবচেয়ে সাধারণ একটা ওয়েব সার্ভার লিখতে বলা হয়, কোন কোন লাইন লিখবে? (কোড না দেখে চেষ্টা করো)**

**৭. `response.writeHead(200, { 'Content-Type': 'text/html' })` — এই লাইনটা কী কাজ করছে, আর এটা বাদ দিলে কী সমস্যা হতে পারে?**

**৮. Cloud VM-এ ডেপলয় করার সময়, লোকাল কম্পিউটারে সার্ভার চালানোর সাথে মূল পার্থক্যটা কোথায়? (ইঙ্গিত: SSH, পাবলিক IP, Firewall)**

## একটা ব্যবহারিক চ্যালেঞ্জ (নিজে করে দেখো)

শুধু প্রশ্নের উত্তর দেয়াই যথেষ্ট না — নিজে হাতে করে দেখাটাই আসল পরীক্ষা। নিচের কাজটা নিজে থেকে করার চেষ্টা করো, কোনো কোড না দেখে:

1. একটা নতুন ফোল্ডার বানাও।
2. সেখানে একটা `about.html` ফাইল বানাও, যেখানে তোমার নিজের সম্পর্কে কিছু লেখা থাকবে।
3. Node.js দিয়ে একটা সার্ভার লেখো যেটা `about.html`-এর কনটেন্ট পড়ে ব্রাউজারে পাঠায়, সঠিক `Content-Type` header সহ।
4. `localhost:4000`-এ (একটা নতুন পোর্ট বেছে নাও) সার্ভারটা চালু করো এবং ব্রাউজারে টেস্ট করো।

যদি এই চ্যালেঞ্জটা নিজে থেকে করতে পারো, বুঝবে Module 2-এর মূল ধারণাগুলো তোমার ভেতরে গেঁথে গেছে।

## সামনে কী আসছে

এই মডিউলে আমরা দেখেছি একটা সার্ভার কীভাবে *একটামাত্র* নির্দিষ্ট ফাইল পাঠাতে পারে। কিন্তু বাস্তব ওয়েবসাইটে অনেক পাতা থাকে — হোমপেজ, প্রোফাইল পেজ, সেটিংস পেজ। কীভাবে একটা সার্ভার বুঝবে ঠিক কোন পাতা কখন পাঠাতে হবে? আর ব্যাকএন্ড ডেভেলপমেন্টে ঠিক কোন কোন টুল আর ধারণা আমাদের লাগবে, সেই বড় ছবিটা কেমন? এই প্রশ্নগুলো নিয়েই শুরু হবে **Module 3 — Introduction to Backend System**।
