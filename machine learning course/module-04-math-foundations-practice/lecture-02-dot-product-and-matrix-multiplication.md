## সমস্যাটা কী?

একজন ছাত্রের score বের করতে প্রতিটা feature-কে তার weight দিয়ে গুণ করে যোগ করতে হয়। 100 জনের জন্য এই কাজ 100 বার। প্রতিটা বার আলাদা করে লিখলে ঝামেলা বাড়ে, ভুলও হয়। Matrix গুণ এই পুরো কাজটা এক লাইনে লেখার উপায়, আর shape-এর নিয়ম বলে দেয় কাজটা করা যাবে কি না।

## ধারণাটা সহজ ভাষায়

**Dot product** দুটো সমান length-এর vector নেয়: অবস্থান ধরে ধরে গুণ করে, তারপর সব গুণফল যোগ করে। ফল একটা সংখ্যা।

`[2, 3] · [0.5, −1] = 2 × 0.5 + 3 × (−1) = 1 − 3 = −2`

এটাই এক উদাহরণের weighted sum। তাই `z = x · w + b`।

**Matrix × vector:** matrix-এর প্রতিটা সারির সঙ্গে vector-এর dot product। ফল: প্রতি সারির জন্য একটা সংখ্যা, মানে একটা vector। সব উদাহরণের score একসঙ্গে।

**Matrix × matrix:** `A × B`-তে ফলের প্রতিটা ঘর হলো `A`-এর একটা সারি আর `B`-এর একটা কলামের dot product।

**Shape-এর নিয়ম:** `(a, b) × (b, c) → (a, c)`। মাঝের দুটো সংখ্যা সমান হতে হবে (কারণ dot product-এ length সমান লাগে), আর সেই দুটো বাদ পড়ে যায়। মাঝের সংখ্যা না মিললে গুণ করাই যায় না।

## ছোট একটা উদাহরণ

3 জন ছাত্র, 2 feature, `w = [0.5, −1]`, `b = 0.5`:

```text
X = [[1, 2], [3, 4], [5, 6]]

সারি 1: 1×0.5 + 2×(−1) = −1.5
সারি 2: 3×0.5 + 4×(−1) = −2.5
সারি 3: 5×0.5 + 6×(−1) = −3.5
```

Shape: `(3, 2) × (2,) → (3,)`। তারপর প্রত্যেকের সঙ্গে `b = 0.5` যোগ: `z = [−1, −2, −3]`। Logistic Regression হলে প্রতিটা z-তে [sigmoid](../module-03-logistic-regression/lecture-01-sigmoid.md) বসে: `p = [0.269, 0.119, 0.047]`।

Matrix × matrix-এর উদাহরণ: `A` shape `(2, 3)`, `B` shape `(3, 2)`। ফলের shape `(2, 2)`।

```text
A = [[1, 2, 3], [4, 5, 6]]
B = [[1, 0], [0, 1], [1, 1]]

(সারি 1, কলাম 1): 1×1 + 2×0 + 3×1 = 4
(সারি 1, কলাম 2): 1×0 + 2×1 + 3×1 = 5
(সারি 2, কলাম 1): 4×1 + 5×0 + 6×1 = 10
(সারি 2, কলাম 2): 4×0 + 5×1 + 6×1 = 11

A × B = [[4, 5], [10, 11]]
```

## কোড

```python
import math

def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

def matvec(X, w):
    return [dot(row, w) for row in X]

def matmul(A, B):
    cols = list(zip(*B))
    return [[dot(row, col) for col in cols] for row in A]

def sigmoid(z):
    return 1 / (1 + math.exp(-z))

print(dot([2, 3], [0.5, -1]))
X, w, b = [[1, 2], [3, 4], [5, 6]], [0.5, -1], 0.5
z = [v + b for v in matvec(X, w)]
print(z, [round(sigmoid(v), 3) for v in z])
print(matmul([[1, 2, 3], [4, 5, 6]], [[1, 0], [0, 1], [1, 1]]))
```

```text
# output:
-2.0
[-1.0, -2.0, -3.0] [0.269, 0.119, 0.047]
[[4, 5], [10, 11]]
```

## মনে রাখার সারকথা

- Dot product: জোড়ায় জোড়ায় গুণ, তারপর যোগ; ফল একটা সংখ্যা।
- `(a, b) × (b, c) → (a, c)`; মাঝের সংখ্যা সমান না হলে গুণ হয় না।
- `z = Xw + b` সব উদাহরণের score দেয়; তারপর sigmoid-এ p, প্রতিটা সংখ্যায় আলাদা করে।
