# Lecture 02 — ভুল মাপা: Error ও Mean Squared Error

> আগে যা জানা থাকলে ভালো: [Lecture 01](lecture-01-prediction-weight-and-bias.md) — `ŷ = w × x + b`। এই lecture শেষে পারবে: একটা ছোট data-তে প্রতিটা অনুমানের error, তারপর MSE হাতে বের করতে।

[Map-এ অবস্থান](../01-learning-map.md): Supervised → Linear Regression → training-এর লক্ষ্য (ভুলের মাপ)। MSE শুধু ভুল মাপে; parameter বদলায় না।

## সমস্যাটা কী?

দুটো model আছে: একটার `w = 1, b = 0`, আরেকটার `w = 2, b = 1`। কোনটা ভালো? এর জন্য আমাদের দরকার অনুমান আর সঠিক উত্তরের পার্থক্যকে একটা সংখ্যায় প্রকাশ করার উপায়। সেই সংখ্যা না থাকলে "ভালো" শব্দটা শুধু অনুভূতি, আর কম্পিউটার সেটা দিয়ে কিছু করতে পারে না। এই সংখ্যাকে বলে **loss**।

## ধারণাটা সহজ ভাষায়

**Error** মানে একটা অনুমান সঠিক উত্তর থেকে কতটা সরে গেছে। এই module-এ আমরা ধরি:

`error = অনুমান − সঠিক উত্তর = ŷ − y`

সঠিক উত্তর 5, অনুমান 2 হলে error `2 − 5 = −3`। ঋণাত্মক মানে কম অনুমান করেছি, ধনাত্মক মানে বেশি।

অনেকগুলো উদাহরণের error একসঙ্গে একটা সংখ্যা করতে গেলে সরাসরি গড় নেওয়া যায় না। দুই উদাহরণে error `+3` আর `−3` হলে গড় 0, অথচ দুটো অনুমানই ভুল। তাই আগে প্রতিটা error-এর **square** (নিজেকে নিজে গুণ) করা হয়, তারপর **গড়** নেওয়া হয়। Square করলে সবই ধনাত্মক হয়ে যায়, আর বড় ভুল আরও বড় হয়ে দেখা দেয়: error 2 হলে square 4, কিন্তু error 4 হলে square 16।

এই গড়ের নাম **Mean Squared Error (MSE)**। (Mean = গড়, Squared = square করা, Error = ভুল।)

## ছোট একটা উদাহরণ

আগের lecture-এর দুটো data point:

| x | সঠিক y |
|---|---|
| 1 | 3 |
| 2 | 5 |

প্রথম model: `w = 1`, `b = 0`, অর্থাৎ `ŷ = 1 × x + 0`।

| x | y | অনুমান ŷ | error ŷ − y | error² |
|---|---|---|---|---|
| 1 | 3 | 1 | −2 | 4 |
| 2 | 5 | 2 | −3 | 9 |

```text
MSE = (4 + 9) / 2 = 6.5
```

দ্বিতীয় model: `w = 2`, `b = 1`।

| x | y | অনুমান ŷ | error | error² |
|---|---|---|---|---|
| 1 | 3 | 3 | 0 | 0 |
| 2 | 5 | 5 | 0 | 0 |

```text
MSE = (0 + 0) / 2 = 0
```

6.5 আর 0 তুলনা করে স্পষ্ট বোঝা গেল দ্বিতীয় model এই data-র জন্য ভালো। এখন "ভালো" মানে একটা সংখ্যা: যার MSE কম।

আরেকটা model `w = 2`, `b = 0` নাও: অনুমান 2, 4; error −1, −1; MSE = (1 + 1)/2 = 1। এটা প্রথমটার চেয়ে ভালো, দ্বিতীয়টার চেয়ে খারাপ।

## Formula / কোড

উপরের হিসাবটারই সংক্ষিপ্ত রূপ:

`MSE = (1/n) × Σ (ŷᵢ − yᵢ)²`

- `n`: উদাহরণের সংখ্যা (এখানে 2)
- `i`: কোন উদাহরণ (1ম, 2য়, …)
- `Σ`: "সবগুলো যোগ করো"

```python
xs = [1, 2]
ys = [3, 5]

def mse(w, b):
    errors = [(w * x + b) - y for x, y in zip(xs, ys)]
    return sum(e * e for e in errors) / len(errors)

print(mse(1, 0), mse(2, 0), mse(2, 1))
# output:
# 6.5 1.0 0.0
```

## মনে রাখার সারকথা

- Error = অনুমান − সঠিক উত্তর। MSE = error-এর square-এর গড়।
- MSE কখনো ঋণাত্মক হয় না; 0 মানে সব অনুমান মিলে গেছে।
- MSE-এর একক target-এর এককের square। target লাখ টাকায় হলে MSE (লাখ টাকা)²; তাই 6.5 মানে "গড়ে 6.5 লাখ ভুল" নয়।

সাবধান: দুটো উদাহরণে MSE 0 হওয়া মানে এই নয় যে model নতুন data-তেও ঠিক। সেটা [Lecture 05](lecture-05-checking-on-new-data.md)-এ।

৩. Error `+3` ও `−3` হলে সরাসরি গড় কত? MSE কত? কোনটা model-এর ভুল ঠিকভাবে ধরে?
