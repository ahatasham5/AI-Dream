# Lecture 03 — Log loss: classification-এর ভুল মাপা

> আগে যা জানা থাকলে ভালো: [Logistic model ও decision boundary](lecture-02-logistic-model-and-decision-boundary.md) এবং [MSE-র ধারণা](../module-02-linear-regression/lecture-02-error-and-mean-squared-error.md)। এই lecture শেষে পারবে: একটা উদাহরণের log loss হাতে বের করতে, আর বলতে পারবে classification-এ MSE-র বদলে কেন log loss নেওয়া হয়। ([Map-এ অবস্থান](../01-learning-map.md): Logistic Regression → training objective, অর্থাৎ ভুল মাপা। এখানে weight বদলানো হয় না)

## সমস্যাটা কী?

দুটো model-এর মধ্যে কোনটা ভালো, বা একই model-এর কোন weight ভালো, বলতে হলে "ভুল"-কে একটা সংখ্যায় মাপতে হয়। Linear Regression-এ আমরা এই কাজে MSE ব্যবহার করেছি। কিন্তু classification-এ model একটা probability দেয়, আর সত্যি উত্তর হলো 0 বা 1। যে model সত্যি উত্তরের ব্যাপারে 99% নিশ্চিত হয়ে ভুল বলেছে, তার ভুল "একটু ভুল"-এর চেয়ে অনেক বেশি গুরুতর হওয়া উচিত। MSE এই পার্থক্যটা ভালোভাবে ধরে না।

## ধারণাটা সহজ ভাষায়

নিয়মটা এক লাইনে: **সত্যি যে class, model তাকে কত probability দিয়েছিল?** বেশি দিলে ভুল কম, কম দিলে ভুল বেশি।

- সত্যি উত্তর `y = 1` হলে, model-এর দেওয়া `p` ই হলো সত্যি class-এর probability।
- সত্যি উত্তর `y = 0` হলে, সত্যি class-এর probability হলো `1 − p`।

এই probability-কে ভুলের সংখ্যায় বদলাতে **log loss** নেয় `−ln(সেই probability)`। `ln` হলো natural logarithm; calculator বা Python `math.log`-এ পাওয়া যায়। এর দুটো আচরণ জানলেই চলে: `ln(1) = 0`, আর ছোট সংখ্যার `ln` বড় ঋণাত্মক। তাই probability 1 হলে loss 0 আর probability 0-এর দিকে গেলে loss অনেক বড় হয়ে যায়।

Log loss-কে **binary cross-entropy**-ও বলা হয়। দুটো একই জিনিস।

## ছোট একটা উদাহরণ

প্রথমে একটা মাত্র উদাহরণ, `y = 1`। পাশে তুলনার জন্য MSE-র মতো squared error `(p − 1)²`-ও রাখলাম:

| model-এর p | log loss = −ln(p) | squared error |
|---|---|---|
| 0.99 | 0.010 | 0.0001 |
| 0.90 | 0.105 | 0.010 |
| 0.50 | 0.693 | 0.250 |
| 0.10 | 2.303 | 0.810 |
| 0.01 | 4.605 | 0.980 |

p = 0.1 আর p = 0.01 দুটোই ভয়ানক ভুল। Squared error বলে 0.81 আর 0.98, প্রায় এক। Log loss বলে 2.3 আর 4.6, ফারাক পরিষ্কার: যত বেশি আত্মবিশ্বাসী হয়ে ভুল, শাস্তি তত বেশি। `y = 0` হলে একই হিসাব, শুধু p-এর জায়গায় `1 − p` বসে: p = 0.9 হলে loss `−ln(0.1) = 2.303`।

## কেন MSE নয়?

দুটো কারণ:

1. **শাস্তির সীমা:** squared error সর্বোচ্চ 1-এ আটকে যায়, তাই "প্রচণ্ড ভুল" আর "ভুল" প্রায় একই মনে হয় (উপরের table)।
2. **শেখার সংকেত:** training-এ loss-এর gradient (ঢাল) দিয়ে weight বদলানো হয়। ধরো `y = 1` কিন্তু `z = −4`, অর্থাৎ p ≈ 0.018, model খুব ভুল। এই অবস্থায় z-এর সাপেক্ষে ঢাল:

| loss | ঢাল (z = −4, y = 1) |
|---|---|
| MSE | প্রায় −0.035 |
| log loss | প্রায় −0.982 |

MSE-র ঢাল প্রায় 28 গুণ ছোট, ফলে সবচেয়ে ভুল অবস্থায় gradient descent প্রায় নড়েই না। Log loss-এ ঠিক এই অবস্থায় বড় ধাক্কা আসে। (ঢালের হিসাব পরের lecture-এ আসবে; এখানে শুধু ফলটা দেখো।)

## পুরো dataset-এর loss

Dataset: x = [1, 2, 3, 4], y = [0, 0, 1, 1] (পড়ার ঘণ্টা আর পাস)। একটা model `p = σ(1 × x − 2.5)` নিয়ে প্রতিটার loss:

| x | y | z | p | সত্যি class-এর probability | loss |
|---|---|---|---|---|---|
| 1 | 0 | −1.5 | 0.182 | 1 − 0.182 = 0.818 | 0.201 |
| 2 | 0 | −0.5 | 0.378 | 0.622 | 0.474 |
| 3 | 1 | 0.5 | 0.622 | 0.622 | 0.474 |
| 4 | 1 | 1.5 | 0.818 | 0.818 | 0.201 |

গড় loss: `(0.201 + 0.474 + 0.474 + 0.201) / 4 = 0.338`। তুলনা:

| w, b | কেমন model | গড় log loss |
|---|---|---|
| 0, 0 | সব p = 0.5, কিছুই জানে না | 0.693 |
| 1, −2.5 | সঠিক দিকে | 0.338 |
| −1, 2.5 | উল্টো দিকে | 1.338 |

ঠিক দিকের model-এর loss কম, উল্টো দিকের বেশি। Training-এর কাজ হলো এই loss কমানো। মনে রাখো, loss কখনো ঠিক 0 হয় না, কারণ p কখনো ঠিক 1 হয় না।

## Formula ও কোড

একটা উদাহরণের জন্য, দুই ক্ষেত্র একসঙ্গে:

`L = −[ y × ln(p) + (1 − y) × ln(1 − p) ]`

`y = 1` হলে দ্বিতীয় অংশ 0 হয়ে যায়, থাকে `−ln(p)`। `y = 0` হলে প্রথম অংশ 0, থাকে `−ln(1 − p)`। সব উদাহরণের গড় নিলে পুরো dataset-এর loss। এটা শুধু ভুলের মাপ; weight এতে বদলায় না।

```python
import math

def sigmoid(z):
    return 1 / (1 + math.exp(-z))

def log_loss_one(y, p):
    return -(y * math.log(p) + (1 - y) * math.log(1 - p))

xs, ys = [1, 2, 3, 4], [0, 0, 1, 1]
w, b = 1, -2.5
losses = [log_loss_one(y, sigmoid(w * x + b)) for x, y in zip(xs, ys)]
print([round(l, 3) for l in losses])
print(round(sum(losses) / len(losses), 3))
```

```text
# output:
[0.201, 0.474, 0.474, 0.201]
0.338
```

## মনে রাখার সারকথা

- Log loss = সত্যি class-কে model যে probability দিয়েছিল, তার `−ln`; probability বেশি হলে loss কম।
- আত্মবিশ্বাসী হয়ে ভুল করলে loss খুব বড় হয়; squared error ওখানে আটকে যায়।
- Classification-এ log loss নেওয়ার আরেক কারণ: খুব ভুল অবস্থায় এর gradient বড়, তাই শেখা আটকায় না।
